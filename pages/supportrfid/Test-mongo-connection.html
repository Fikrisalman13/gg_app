Test Koneksi MongoDB

Halaman ini adalah front-end sederhana yang memanggil endpoint backend untuk menguji koneksi ke MongoDB di localhost:27017, database test_update dan koleksi picking_process.

Hasil

Belum diuji.

Catatan penting

  • Browser tidak bisa langsung terhubung ke MongoDB — diperlukan backend (Node.js/Express) yang menjalankan driver MongoDB.
  • Di bawah terdapat contoh server.js (Node/Express) yang harus Anda simpan & jalankan di mesin yang sama dengan MongoDB.

Contoh server.js (save sebagai server.js)

// server.js
const express = require('express');
const { MongoClient } = require('mongodb');
const cors = require('cors');

const app = express();
app.use(cors());
app.use(express.json());

// Ubah sesuai kebutuhan
const MONGO_URI = process.env.MONGO_URI || 'mongodb://localhost:27017';
const DB_NAME = process.env.DB_NAME || 'test_update';
const COLLECTION = process.env.COLLECTION || 'picking_process';

let client;

async function connectOnce(){
  if (client && client.isConnected && client.isConnected()) return client;
  client = new MongoClient(MONGO_URI, { useUnifiedTopology: true });
  await client.connect();
  return client;
}

app.get('/test-mongo', async (req, res) => {
  try{
    const uri = req.query.uri || MONGO_URI;
    const dbName = req.query.db || DB_NAME;
    const col = req.query.col || COLLECTION;

    // koneksi baru per request agar predictable
    const tmpClient = new MongoClient(uri, { useUnifiedTopology: true });
    await tmpClient.connect();
    const db = tmpClient.db(dbName);
    const collection = db.collection(col);

    // contoh operasi ringan: hitung dokumen (fast) dan temukan 1 dokumen
    const count = await collection.countDocuments();
    const one = await collection.findOne({}, { projection: { _id: 1 } });

    await tmpClient.close();

    res.json({ ok: true, message: 'Koneksi berhasil', count, sampleId: one ? one._id : null });
  }catch(err){
    res.status(500).json({ ok: false, message: 'Koneksi gagal', error: err.message });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, ()=> console.log(`Server listening on http://localhost:${PORT}`));

Instruksi singkat menjalankan

  1. Simpan file di atas sebagai server.js di folder baru.
  2. Jalankan: npm init -y lalu npm install express mongodb cors
  3. Jalankan server: node server.js (atau set env MONGO_URI/DB_NAME/COLLECTION jika ingin berbeda)
  4. Buka file index.html (file ini) di browser, klik Jalankan Tes Koneksi.

Jika server berjalan di mesin yang sama, front-end akan memanggil http://localhost:3000/test-mongo dengan parameter URI, DB, dan collection.
