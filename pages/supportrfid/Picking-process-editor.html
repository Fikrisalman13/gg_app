Catatan & Backend

  • Front-end ini tidak terhubung langsung ke MongoDB. Dibutuhkan backend (mis: Node.js + Express) yang mengekspos REST API.
  • Contoh endpoint yang dibutuhkan (asumsi base http://localhost:3000): 
    GET  /api/picking-process?limit=25&q=...      -> list dokumen (JSON)
GET  /api/picking-process/:id                 -> ambil satu dokumen
POST /api/picking-process                     -> tambah dokumen (body = JSON)
PUT  /api/picking-process/:id                 -> update dokumen (body = JSON)
DELETE /api/picking-process/:id               -> hapus dokumen
  • Pastikan backend melakukan konversi ObjectId dan mengembalikan/menerima JSON murni.
