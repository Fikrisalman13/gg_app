        │             │
        ↓             ↓

        │             │
        └──────┬──────┘
               ↓
┌─────────────────────────────┐
│ /ip/dhcp-server/lease/      │
│   make-static               │ ← Make static

               ↓
┌─────────────────────────────┐
│ /ip/dhcp-server/lease/set   │
│ (comment)                   │ ← Set comment
└─────────────────────────────┘

OPERATION 3: Simple Queue

│ /queue/simple/print         │

📋 CRITICAL VARIABLES & VALUES
─────────────────────────────────────────────────────────────────────────────

COMMENT FORMAT:
  Template: "{dept} - {nama} ({device})"
  Example: "Marketing - Lidiya Nurhalimah (Laptop)"
  Applied to: ARP comment, DHCP comment, Queue name, Firewall comment

BANDWIDTH LIMITS:
  Values: unlimited, 64k, 128k, 256k, 384k, 512k, 768k, 1M, 2M, 4M, 5M, 10M,
          20M, 50M, 100M
  Format in Queue: "{bw_up}/{bw_down}" e.g. "512k/2M"

DEVICE TYPES:
  Values: PC, Laptop, Tab, HP, Printer, Server, CCTV

MIKROTIK PATHS:
  ARP: /ip/arp
  DHCP: /ip/dhcp-server/lease
  Queue: /queue/simple
  Firewall: /ip/firewall/address-list
