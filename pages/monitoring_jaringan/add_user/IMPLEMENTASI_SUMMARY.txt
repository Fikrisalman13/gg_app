🔄 WORKFLOW LENGKAP
═══════════════════════════════════════════════════════════════════════════════

START
  ↓
[1] FORM LOAD (add_user.php)
    ├─ Fetch ARP List (filter: no comment + DHCP/DC status)
    ├─ Fetch DHCP Leases
    ├─ Fetch Firewall Lists
    └─ Fetch Employee Data (aktif=1)
  ↓
[2] USER SELECTS IP
    └─ Trigger: $.ajax → get_dhcp_leases.php
    └─ Result: DHCP dropdown auto-populated
  ↓
[3] USER FILLS EMPLOYEE & DEVICE
    └─ onChange: Update comment preview real-time
    └─ Format: "Departemen - Nama (Device Type)"
  ↓
[4] USER OPTIONAL: MAKE STATIC (ARP/DHCP)
    └─ Click buttons to prepare IP before final submit
    └─ AJAX calls to make_static_arp.php / make_static_dhcp.php
  ↓
[5] USER OPTIONAL: ADD FIREWALL
    └─ Click "OK" to add IP to firewall
    └─ AJAX call to add_firewall.php
  ↓
[6] USER SELECTS BANDWIDTH & SUBMITS
    ├─ Client validation (all required fields)
    ├─ POST to proses_add_user.php
    └─ Return success/error message
  ↓
[7] PROCESSING (proses_add_user.php)
    ├─ Fetch ARP data & validate
    ├─ Check queue duplicate
    ├─ Make ARP static + set comment
    ├─ Handle DHCP lease (create if needed)
    ├─ Create simple queue (name + target + max-limit)
    ├─ Add firewall (optional)
    └─ Return success/error via session
  ↓
[8] REDIRECT & SHOW RESULT
    └─ Success: Show all created items details
    └─ Error: Show error message & instructions
  ↓
END

📚 DATABASE QUERIES DIGUNAKAN
═══════════════════════════════════════════════════════════════════════════════

1. GET ACTIVE EMPLOYEES:
   SELECT m_emp.nik, m_emp.nama_lengkap, m_bag.bagian, m_dept.dept 
   FROM dbo.m_emp 
   LEFT JOIN dbo.m_bag ON m_emp.id_bag = m_bag.id_bag 
   LEFT JOIN dbo.m_dept ON m_emp.id_dept = m_dept.id_dept 
   WHERE m_emp.aktif = 1 
   ORDER BY m_emp.dept ASC, m_emp.nama_lengkap ASC

2. GET EMPLOYEE DEPARTMENT:
   SELECT m_bag.bagian, m_dept.dept 
   FROM dbo.m_emp 
   LEFT JOIN dbo.m_bag ON m_emp.id_bag = m_bag.id_bag 
   LEFT JOIN dbo.m_dept ON m_emp.id_dept = m_dept.id_dept 
   WHERE m_emp.nama_lengkap = ? AND m_emp.aktif = 1
